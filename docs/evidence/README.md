# Evidencia de desarrollo

Esta carpeta sólo contiene instrucciones hasta que existan ejecuciones reales. Registrar cada ciclo en `tdd/<task-id>.md`: escenario, test, comando RED, código de salida y motivo, cambio mínimo, comando GREEN y resultado, refactor, suite de regresión, commit/patch y revisión.

Para setup: `engram-setup.md` con versión, entorno, proyecto resuelto y recuperación tras reinicio. Para evaluación: manifiesto de corrida y resultados reales. Nunca subir claves, texto personal ni falsificar una salida para completar una plantilla.
