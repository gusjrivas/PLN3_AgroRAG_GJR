# ADR-009: Seguridad y operación local proporcionadas

Estado: propuesto. Fecha: 21/10/2026. Responsable: coordinador; revisión humana: Gustavo Julián Rivas.

## Contexto

El corpus puede contener instrucciones y el modelo puede inventar citas. El POC debe tener controles sin requerir plataforma corporativa.

## Decisión propuesta

Loopback por defecto, API key reader/admin, CLI de ingesta, input/output validado, tools allowlist, límites de recursos, logs sin secretos. Salidas operativas con HTTP tipado y catálogo autorizado para citas.

## Alternativas

Sin auth ni límites: incumple robustez. OAuth corporativo/multitenancy en MVP: carga innecesaria. Confiar sólo en sanitización regex o en prompt: defensa insuficiente.

## Consecuencias y límites

No apto para exposición pública sin nuevo ADR y controles adicionales. Una API key compartida reader corresponde a demo single-user, no identidades personales.

## Verificación y condición de revisión

401 en llamada sin clave, input excesivo rechazado, injection no dispara herramientas externas, traversal bloqueado, secretos ausentes en logs y UI.

Cambio relacionado: `05-frontend-hardening`. Si las pruebas o restricciones invalidan la decisión, registrar evidencia y redactar ADR sucesor antes de modificar el contrato.
