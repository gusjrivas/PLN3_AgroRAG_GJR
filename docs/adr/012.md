# ADR-012: primera versión incremental con corpus piloto

Estado: aplicado al incremento inicial por pedido del usuario de comenzar el desarrollo y producir una primera versión. Fecha: 22/10/2026. Revisión: misma sesión.

## Decisión

Entregar primero un catálogo SQLite de fuentes curadas y un baseline lexical ejecutable. `catalogue_preview` identifica la activación local y no sustituye el namespace Pinecone planificado. Los requisitos de recuperación semántica, reranking, evaluación y preproducción completa continúan abiertos.

La primera versión conecta luego investigador y verificador mediante un puerto de generación configurable y una UI HTTP. Sin proveedor real configurado, informar indisponibilidad del generador; no simular una respuesta del modelo. Las pruebas pueden inyectar agentes deterministas, diferenciadas de integración científica real.

## Motivo y límites

Permite revisar procedencia y comportamiento antes de gastar llamadas o cargar modelos. No exige credenciales de Pinecone para comenzar. Engram local de cada cliente puede configurarse en paralelo y no bloquea ejecución del producto. Las alternativas hybrid/local se compararán en dev conforme ADR-005; este incremento no acredita cumplimiento de toda la consigna.

## Consecuencia

Mantener explícitos los modos, fuentes incluidas y pendientes. Cada PR funcional debe superar TDD y los checks disponibles, con evidencia real. No archivar etapas completas por haber entregado un corte parcial.
