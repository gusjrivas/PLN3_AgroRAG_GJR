# ADR-001: Repositorio independiente y reuso trazable

Estado: propuesto. Fecha: 21/10/2026. Responsable: coordinador; revisión humana: Gustavo Julián Rivas.

## Contexto

El usuario exige separar el TP del repositorio docente. El código de ejemplo sirve de base, pero mezclar ambas evoluciones dificulta atribución y entrega.

## Decisión propuesta

Repositorio PLN3_AgroRAG_GJR independiente; src/tests/docs/openspec en raíz. Referenciar el commit docente 1f4cdbb y adaptar módulos bajo tests de caracterización. Registrar cada módulo reutilizado, su licencia/atribución y cambios en THIRD_PARTY.md al incorporarlo.

## Alternativas

Rama en PLN3_GJR: descartada por instrucción explícita. Fork con todo el material: agrega historial y archivos ajenos al producto. Repo nuevo con copia indiscriminada: dificulta distinguir aporte.

## Consecuencias y límites

Se pierde actualización automática del ejemplo; toda incorporación posterior se revisa como cambio explícito. El usuario creó el remoto independiente y proporcionó su URL. Esta carga no modifica su visibilidad.

## Verificación y condición de revisión

Git nuevo no contiene carpetas Teoria*. El inventario de procedencia identifica módulos adaptados sin atribuirse autoría ajena.

Cambio relacionado: `00-foundation`. Si las pruebas o restricciones invalidan la decisión, registrar evidencia y redactar ADR sucesor antes de modificar el contrato.
