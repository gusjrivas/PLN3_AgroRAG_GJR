# ADR-003: Python y arquitectura modular con puertos

Estado: propuesto. Fecha: 21/10/2026. Responsable: coordinador; revisión humana: Gustavo Julián Rivas.

## Contexto

Usuario exige Python, buenas prácticas de backend/frontend/arquitectura y TDD. El ejemplo mezcla configuración global e inicialización de servicios.

## Decisión propuesta

Python 3.12 con paquete src, FastAPI, Pydantic v2, application/domain independientes de frameworks, interfaces Protocol e inyección en bootstrap. Configuración tipada desde entorno/archivos, sin carga de modelos al importar.

## Alternativas

Scripts monolíticos: impiden aislamiento. Microservicios: costo operativo innecesario. Arquitectura genérica con capas vacías: no aporta al POC.

## Consecuencias y límites

Más interfaces pequeñas, pero permite fakes y tests rápidos. Versiones de librerías se resuelven y fijan en 00; no asumir que versiones del ejemplo son compatibles.

## Verificación y condición de revisión

Tests de importación impiden dependencias inversas. Un test de salud con providers fake no requiere red ni secretos. uv.lock reproduce entorno.
