# ADR-005: RAG híbrido preservando patrón docente

Estado: propuesto. Fecha: 21/10/2026. Responsable: coordinador; revisión humana: Gustavo Julián Rivas.

## Contexto

La cátedra proporciona BM25, embeddings/Pinecone, RRF y Cross-Encoder; mantenerlos permite comparar aportes.

## Decisión propuesta

Reusar patrón con adaptadores. Baselines BM25 y vectorial, luego híbrido y reranking. Separar source_id/page_id/evidence_id. Diversidad por source_id con cap configurable. Multilingual-e5-small y BGE-reranker-v2-m3 son candidatos iniciales, sujetos a benchmark de CPU en dev antes de fijar.

## Alternativas

Cambiar a otra base vectorial desde el inicio: reduce reuso. Dense-only: omite comparación híbrida. GraphRAG/fine-tuning: complejidad fuera de alcance.

## Consecuencias y límites

Pinecone necesita acceso/credenciales en integración real. Prefijos e5 y revisión exacta de modelos se registran. Cambiar embeddings crea nuevo índice/namespace compatible, nunca mezcla espacios aunque tengan igual dimensión.

## Verificación y condición de revisión

Mismos chunks y qrels para comparaciones. Prefijos query:/passage: probados. No reportar fallback BM25 como híbrido. Una caída de vector produce error explícito en modo híbrido.

Cambio relacionado: `03-retrieval`. Si las pruebas o restricciones invalidan la decisión, registrar evidencia y redactar ADR sucesor antes de modificar el contrato.
