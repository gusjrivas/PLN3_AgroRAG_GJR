# Proposal: Memoria local de agentes de desarrollo

## Why

Avanzar el TP AgroRAG independiente con calidad preproductiva, Python y TDD. Esta etapa cubre MEM-01, MEM-02 y sus escenarios observables, conforme a docs/requirements.md.

## What Changes

- La integración de desarrollo MUST identificar pln3-agro-rag y demostrar recuperación de memoria tras reinicio en cada cliente declarado integrado.
- El producto MUST ejecutarse sin Engram; Git y los contratos SHALL prevalecer frente a recuerdos desactualizados.

## Capabilities

### New Capabilities

- `engram`: memoria local de agentes de desarrollo.

### Modified Capabilities

Ninguna capacidad vigente. Se trata de implementación inicial aún pendiente.

## Impact

Propietario: Coordinador. Rutas objetivo: docs/setup-engram.md; .engram/config.json; docs/evidence/engram-setup.md. Dependencias: 00-foundation. Decisiones: ADR-002.
No modificar el repositorio docente. No ampliar a sensores, riego automático, fine-tuning o infraestructura productiva completa. No marcar esta propuesta como implementada por estar validada su sintaxis.
